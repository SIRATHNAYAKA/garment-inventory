## 📌 About The Project

**Garment Inventory Management System** is a web-based business management application developed to simplify and automate inventory-related operations in garment businesses.

The system provides a centralized platform for managing garment products, stock movements, warehouses, suppliers, purchasing, production, quality control, sales, customers, employees and business reports.

It is designed with a modular architecture using **PHP, MySQL, HTML, CSS and JavaScript**, making it suitable for small and medium-sized garment businesses as well as an academic software development project.

# ⚙️ Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/SIRATHNAYAKA/garment-inventory.git
```

Or download the repository as a ZIP file from GitHub.

---

## 2. Move the Project

If you are using XAMPP, move the project into:

```text
C:\xampp\htdocs\
```

The final path should look like:

```text
C:\xampp\htdocs\garment-inventory
```

---

## 3. Start XAMPP

Open XAMPP Control Panel and start:

* Apache
* MySQL

---

## 4. Create the Database

Open:

```text
http://localhost/phpmyadmin
```

Create a new MySQL database.

Example:

```text
garment_inventory
```

---

## 5. Import Database

Navigate to:

```text
database/
```

Import the provided SQL database file into the newly created database.

---

## 6. Configure Database Connection

Open:

```text
config/database.php
```

Update the database configuration according to your local environment.

Example:

```php
$host = 'localhost';
$dbname = 'garment_inventory';
$username = 'root';
$password = '';
```

---

## 7. Run the Application

Open your browser and visit:

```text
http://localhost/garment-inventory/
```

You can then access the login page and start using the system.
